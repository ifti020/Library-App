# 📚 BoiSync

## 📌 Overview

**BoiSync** is an online library platform currently under development. The platform allows users to browse and search books, view book details and availability, while providing a foundation for future book lending and library management features.

Built with **React (Frontend)**, **Spring Boot (Backend)**, and **MySQL (Database)**, the project focuses on developing a responsive web interface and RESTful backend services.

## ⚙️ How It Works

### 📖 Book Browsing

Users can browse books retrieved from the backend and displayed through the React web interface.

### 🔍 Book Search

Users can search for books by title and filter books by category.

### 📄 Pagination

Books are retrieved and displayed using paginated API responses to manage larger collections of books efficiently.

### 📚 Book Details

Users can open a book details page to view available information about a selected book, including its availability.
